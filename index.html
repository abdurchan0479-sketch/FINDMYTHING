INTEGRATION GUIDE

Connecting FINDMYTHING to Firebase

Follow these 4 quick steps to connect Authentication and Cloud Firestore (No Cloud Storage required!).

1. Create Firebase Project
Visit Firebase Console → Click Add Project → Name it (e.g. campus-findmything).
2. Enable Firebase Authentication
In Firebase Console → Build → Authentication → Click Get Started → Enable Email/Password provider.
3. Enable Cloud Firestore Database
In Firebase Console → Build → Firestore Database → Click Create Database → Start in Test or Production mode.
4. Add Web App & Insert Credentials
Project Settings (⚙) → General → Your apps → Add Web App (</>) → Copy the firebaseConfig object into firebase-config.js.
Security Rules Deployment: Deploy the provided firestore.rules using the Firebase CLI (firebase deploy --only firestore:rules) or by pasting it into the Firebase Console Firestore Rules tab.
